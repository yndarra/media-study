# media-study

Инструмент для изучения английского по видео (в будущем — и по аудио):
скачивает ролик, распознаёт слова, режет на фразовые фрагменты с
гарантированным полным покрытием таймлайна, и даёт локальный веб-редактор
для покадровой правки границ, удаления, объединения и разделения фрагментов.

Источник сейчас — YouTube через `yt-dlp`; в дальнейшем планируется
поддержка аудио-формата и уже готовых локальных видеофайлов (не только
скачанных этим инструментом с YouTube).

## Установка

```
py -3.12 -m pip install -r requirements.txt
```

## Фаза 1 — нарезка на фразы

Проще всего — `process_video.bat` (ссылку передать аргументом или ввести по
запросу): этап 1 в своём окне, затем открывается редактор. Повторный запуск
с той же ссылкой продолжает с места обрыва (скачанный мастер, копия для
редактора и распознавание не переделываются).

```
py -3.12 -m phase1_ingest.cli <url> --project-dir data/<id> [--transcript path/to/transcript.txt]
```

`--transcript` — необязательный путь к пользовательскому текстовому файлу
без таймкодов (например, вики-транскрипт игры); если указан, используется
вместо субтитров YouTube как источник канонического текста, с выравниванием
по словам ASR.

Где резать речь на фразы, решает `phase1_ingest/boundaries.py`: у каждой
границы между словами есть оценка из модели SaT (wtpsplit, по смыслу текста
распознавания, без опоры на пунктуацию — годится и без субтитров), из
пунктуации и переносов строк источника, пауз и штрафа за разрез после
служебных слов; разрезы выбираются оптимально сразу для всего видео с ценой
длины, настроенной по ручной разметке (обычно 2–4 строки, ~1–7.5 с).
Предсказания модели кэшируются в `raw/sat_boundary_probs.json` (первый
расчёт ~1 мин, дальше пересборка — секунды). Фрагменты, где в источнике
намного больше текста, чем прозвучало, получают пометку «проверить текст».

Результат в `data/<id>/`:
- `source_raw.mp4` — мастер в максимальном качестве (для экспорта в Anki);
- `source.mp4` — копия для редактора: не больше 720p, постоянный fps,
  каждый кадр ключевой (all-intra) — точная и быстрая покадровая перемотка;
- `manifest.json` — фрагменты; `waveform.bin` — звуковая волна для дорожки.

После изменений алгоритма нарезки проект можно пересобрать без повторного
скачивания и распознавания речи (ручные правки заменятся, старый манифест
сохранится как `manifest.bak-<дата-время>.json`; настройки из блока
`settings` переносятся в новый манифест):

```
py -3.12 -m phase1_ingest.rebuild --project-dir data/<id> [--transcript file.txt] [--remake-proxy]
```

## Настройки проекта

В начале `data/<id>/manifest.json` есть блок `settings`:
- `context_padding_seconds` (по умолчанию 3) — запас до и после отрезка на
  дорожке. Применяется сразу при следующем открытии редактора.
- `min_filler_seconds` (по умолчанию 1) — с какой длины тишина/музыка
  становится отдельным фрагментом. Влияет на нарезку — применяется при
  пересборке.

## Фаза 2 — веб-редактор

Приложение одно на все видео (`open_editor.bat` или `py -3.12 -m webapp.run`).
Меню (снизу вверх — по ходу работы): «Добавить» (ссылка YouTube или свой
файл — видео или аудио), «Обработка» (этап 1: к видео можно прикрепить
ссылки на текст для сверки, например страницу Notion, и запустить; ход с
процентами), «Видео» (готовые видео по авторам, прогресс Anki, проверка
флагов в Anki, страница видео со статистикой и «Править»), «Настройки»
(корень колоды Anki, запас по умолчанию, обрабатывать ли сразу после
добавления); внизу — «Сейчас идёт» (скачивание, обработка, выгрузка в Anki
с процентом и временем). Панели скрываются кнопками. Справа в редакторе —
список всех фрагментов: цвет текста — состояние правки (жёлтый — изменён,
красный — удалён, оранжевый ⚑ — вернулся из Anki), зелёный номер — фрагмент
прошёл этап 3; фильтры «требуют доработки» и «помечены в Anki». Редактор
открывает видео на последнем изменённом фрагменте.

Источник текста с репликами «Имя: текст» (сценарии игр): имя говорящего
остаётся в начале строк фрагмента; куски источника, которых нет в речи,
отбрасываются; ссылки Notion читает `phase1_ingest/sources/notion.py`.
Карточки Anki — тип «1.0 Левобережье» (лицо: клип + текст; оборот пока
пустой), код видео и фрагмента — в теге `media-study::<видео>::<фрагмент>`.

```
py -3.12 -m webapp.run --project-dir data/<id> [--port 8000]
```

Откройте `http://127.0.0.1:8000/` в браузере — либо просто дважды
кликните `open_editor.bat` (закрывает уже запущенный редактор, запускает
сервер в отдельном окне и открывает страницу; если страница уже открыта,
новую вкладку не открывает — открытая сама перезагрузится, самая свежая из
копий, остальные пометят себя устаревшими; необязательный аргумент — папка
проекта, по умолчанию уже готовое тестовое видео `data\gTKS8SAwUzE`).

Управление: клик по дорожке — текущий кадр; треугольники под дорожкой —
границы отрезка (клик выделяет границу, после этого ±1/±10 и стрелки
←/→ двигают её, а не текущий кадр; клик по дорожке возвращает выделение
текущему кадру). Жёлтый треугольник с пунктиром — метка, откуда начато
воспроизведение (клик по нему возвращает туда текущий кадр; клик по
треугольнику границы её убирает). На дорожке серый — запас, голубой — отрезок,
желтоватый — кадры, добавленные в отрезок или ушедшие из него при сдвиге
границ. У фрагментов «проверить текст» (фиолетовый статус) волна внутри отрезка светло-фиолетовая.
Жёлтая метка — жёлтый треугольник и линия; если текущий кадр стоит на ней, у текущего
кадра жёлтый треугольник. Двойной клик по кадру дорожки ставит метку туда,
двойной клик по её треугольнику — удаляет; если зажать её треугольник, текущий
кадр сливается с ней, и их можно тянуть вместе.

Клик по видео — то же, что Play/пауза. Повтор (голубой треугольник) — всегда
с первого кадра отрезка; повтор с жёлтой метки (жёлтый треугольник) — серый,
если метки нет. Жёлтая метка ставится только Play после ручного выбора
текущего кадра на дорожке (клик или перетаскивание красного треугольника) и
никогда не на первый кадр отрезка. Звук играет через Web Audio из несжатой дорожки `audio.pcm` (извлекается
из мастера один раз, ~3 с; сервер отдаёт кусок на окно фрагмента), с
точностью до сэмпла: старт ровно с кадра, остановка ровно в конце последнего
кадра отрезка. Видео играет без звука и подстраивается под звук; кадр
остановки на время доигрывания замораживается снимком поверх видео. Кнопка режима (иконка меняется)
— остановка на конце отрезка: Play до последнего кадра
отрезка остановится ровно на нём, Play с него или правее — играет до правого
края фрагмента. Выключена — всегда до правого края фрагмента или до паузы.
Дальше правого края фрагмента воспроизведение не идёт никогда; Play на нём
начинает с жёлтой метки (или с начала отрезка).

Текст фразы (белый, между серыми соседними) правится прямо на месте по
клику. Кнопки «назад»/«вперёд» справа под видео (или Ctrl+Z / Ctrl+Y вне
текста) отменяют и возвращают правки текущего фрагмента: у каждого фрагмента
своя история, и отмена не переводит на другой фрагмент. Действие, задевшее
несколько фрагментов (объединение, разделение), есть в истории каждого из
них. История живёт, пока открыт сервер редактора.

Полный сброс всех правок к результату этапа 1 — `reset_all_edits.bat`
(спросит подтверждение, закроет редактор, пересоберёт манифест за пару
секунд, старый сохранит как manifest.bak-<дата-время>.json, откроет редактор).

Горячие клавиши (работают и в русской раскладке, вне текста): A / D —
предыдущий / следующий фрагмент; Shift+A / Shift+D и ←/→ — кадр назад /
вперёд (или выделенная граница); Пробел — пауза / воспроизведение; W — повтор с начала отрезка;
Shift+Пробел (или Ctrl+Пробел) — повтор с жёлтой метки (нет метки — ничего);
зажатый Shift во время воспроизведения — скорость 2×, пока держишь; автозапуск
(кнопка «▶A» справа от режима остановки, выключается и запоминается): переход к
фрагменту, клик или протяжка по дорожке и нажатие/сдвиг левой границы отрезка сразу
запускают воспроизведение (треугольники текущего кадра, метки и правой границы — нет); S — пометить на удаление; R — говорящий Rover (ещё раз — как было; кнопки ‹ × R › у «Не озвучено»); Q / E —
начало отрезка к концу предыдущего / конец отрезка к началу следующего (кнопки у запаса ±3 с); Shift+Q / Shift+E — выделить начало /
конец отрезка; Shift+W — выделить текущий кадр; Ctrl+Z / Ctrl+Shift+Z —
назад / вперёд. В тексте: новый (набранный или вставленный) текст зелёный,
удалённый исходный остаётся на месте красным (в текст не входит), пробелы
среди нового/удалённого отмечены зелёной/красной точкой, новый перенос строки — зелёным «↵»; набор или
вставка того же символа перед красным возвращает его в белый. Ctrl+Z /
Ctrl+Shift+Z отменяют правки текста, Esc — выйти из текста.

Две пары «−3 с»/«+3 с» в ряду с кадрами меняют запас слева и справа от
отрезка только у текущего фрагмента (серая метка «запас N с · M с»; правкой
не считается, но Reset возвращает его к общему). У края видео «+5 с» добавляет сколько осталось, «−3 с» не
опускает запас ниже 3 с. Удаление оставляет на том же фрагменте, повторное
нажатие «удалить» или Reset снимает пометку удаления (у разделённого —
убирая его части, у исходника объединения — отменяя объединение).
Разделение возможно только строго внутри отрезка (не в запасе и не на его
крайних кадрах), оставляет на исходном фрагменте, части встают слева и
справа от него.

## Фаза 3 — клипы и карточки Anki

Кнопка «добавить в Anki» внизу редактора передаёт на этап 3 все фрагменты с
первого по текущий. Они сразу становятся только для просмотра (желтоватый фон,
статус «в очереди в Anki» → «в Anki ✓»), а работу делает отдельный фоновый
процесс `phase3_export.worker` — он не зависит от редактора (можно дальше
править остальные фрагменты, перезапускать редактор, переключаться на другое
видео), повторное нажатие просто добавляет фрагменты в очередь. Слева от
кнопки — оставшееся время («ждёт Anki», если Anki закрыт: клипы режутся, а
карточки создадутся, когда он откроется).

Для каждого живого фрагмента с текстом, в `data/<id>/export/`:
- `0001.mp4, …` — клип из мастера (исходное 4K), вырезанный точно по
  границам: видео — ровно кадры отрезка, звук — те же сэмплы, что звучат в
  редакторе (`audio.pcm`); H.265 (libx265, CRF 18) + AAC 192k, MP4 (hvc1).
  Если клип больше ~95 МБ (лимит AnkiWeb — 100 МБ на файл) — перекодируется
  в 2K, затем в Full HD;
- `0001.txt, …` — текст фрагмента; `index.json` — общий список (клип, текст,
  фрагмент, границы, id карточки Anki);
- карточка в Anki (через AnkiConnect): колода `settings.anki_deck` манифеста
  (по умолчанию `Claude::2. VIDEOS::<канал>::<видео>`), тип заметок
  `media-study`; лицо — клип (`[sound:<видео>_0001.mp4]`, играет сам) и под
  ним текст, оборот пока пустой. В заметке хранятся код видео и номер
  фрагмента — для будущего возврата помеченных флагом карточек на правку.

Переданные фрагменты помечаются exported: после перезапуска редактора их не
видно, пересборка этапа 1 (`rebuild`, `reset_all_edits.bat`) их не трогает.
То же без редактора — `export_clips.bat` (спросит номер фрагмента).

Какое видео открывать: `open_editor.bat` без аргумента берёт последнее
обработанное (`data/current_project.txt`), другое — перетащите его папку из
`data\` на батник.

## Поздний проход — компактификация

После того как редактирование завершено, все status=="deleted" фрагменты
(мягко удалённые, поглощённые merge/split) можно физически убрать из
манифеста:

```
py -3.12 -m scripts.compact_manifest --project-dir data/<id>
```

```
py -3.12 -m unittest discover -s tests -v
```
